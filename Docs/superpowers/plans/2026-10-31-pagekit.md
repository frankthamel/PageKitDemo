# PageKit, NewsClient and Demo App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the PageKit open-source library, a NewsClient package, and a retro SwiftUI news app that demonstrates both pagination styles.

**Architecture:** `Paginator` is the only public engine type. It reads memory, then disk, then a `PageSource`, and publishes one `PaginationSnapshot` per change over `AsyncStream`. The app supplies `PageSource`s built on `NewsService`, which has live and mock implementations, and renders snapshots with MVVM.

**Tech Stack:** Swift 6, Swift Concurrency, Foundation, Network, CryptoKit, os, SwiftUI, Swift Testing, XCTest (UI tests only), DocC, GitHub Actions.

**Spec:** `Docs/superpowers/specs/2026-10-31-pagekit-design.md`. Behaviour source: `Docs/Building PageKit A Reusable Swift Pagination Library.md` ("the Doc", cited as §n). Read both. Where they conflict, the spec wins.

## Global Constraints

- PageKit: `swift-tools-version: 6.0`, iOS 15, macOS 12, tvOS 15, watchOS 8, `dependencies: []`.
- PageKit imports only Foundation, Network, CryptoKit, os. Never SwiftUI, UIKit or AppKit.
- No iOS 16+ APIs in PageKit: use `Task.sleep(nanoseconds:)`, not `Clock`.
- Zero warnings under `swift build -Xswiftc -strict-concurrency=complete`.
- Every public PageKit symbol has a DocC comment in plain English.
- Defaults: `prefetchDistance` 5, `lookaheadPages` 1, memory 20 MB, disk 50 MB, `maxAge` 7 days, `countLimit` 200, retry 3 attempts, base 0.5 s, max 8 s, jitter 0.5...1.0, eviction target 80%, request timeout 15 s, read-ahead cap 2.
- After every `await` in `Paginator`, re-check generation and state before mutating.
- `NewsClient` target has no networking and no PageKit dependency.
- The app never shows The Economist's name, logo or wordmark. App name: **The Orbital**.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Stay clean and tidy: one responsibility per file, no abstraction without a second implementation or a test that needs it.

## Review Focus

1. A corrupt or truncated `manifest.json` or page file: treated as a cache miss, deleted, and the feed loads from network. No crash. (Task 4)
2. A server page that is empty but still has a `nextToken`: never spins forever. `.empty` on first page if no items; otherwise `.loaded(hasMore: true)` and no automatic refetch from `itemAppeared`. (Task 7)
3. Duplicate IDs inside one page, or a page that is all duplicates: the list stays unique and `indexByID` stays correct. (Task 7)
4. `feedID`s containing `/`, spaces or Unicode (search queries): folder names stay legal and two feeds never collide. (Task 4)
5. `cancel()` during a load, then `snapshots()` called after cancel: stream finishes, no hang, no state change from the late result. (Task 10)
